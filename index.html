01 · 为什么先做网页原型

有想法时，
先做一个能玩的版本。

我会做设计，也做音乐。想到一个音画交互时，我现在不会先问“要把哪个软件学完”，而是先让 AI 帮我搭一个能按、能听、能修改的网页。真正玩过一次，才知道这个想法有没有意思。

浏览器直接运行 可以发给别人试玩 反馈后继续修改
我最开始说的话其实很简单
“我想做一个只有一个按钮的音画乐器。点一下、按住、松开，应该是三段不一样的过程。”
网页原型的价值不是看起来像成品，而是让脑子里的感觉尽快变成一次真实操作。
02 · 先验证最小关系

同一个输入，
能不能有时间感？

短按不是“缩短版长按”，松手也不是直接停止。每个动作都应该有能听见、也能看见的区别。

TAP短按：约 0.12 秒的瞬间声音和紧凑视觉事件
PRESS按下：先出现一小段 opening phrase，告诉人“系统开始了”
HOLD超过 350ms：进入持续节奏、Drone 或 Arpeggio
RELEASE停止产生新事件，但保留 2–3 秒尾音和视觉残影
直接点击或长按右侧画面；这一页也可以按住 SPACE 演奏。

03 · 第一轮怎么写 Prompt

我会把五件事一次写清，
再让 AI 开始搭。

可以直接复制的起始 Prompt
请做一个浏览器里的实验电子音画乐器。

声音使用 Web Audio API 或 Tone.js；
视觉使用 Canvas 或 WebGL。
只保留一个主要输入，并建立统一的 BPM / Transport。

Tap：触发约 0.12 秒的短促声音和紧凑视觉事件。
Press：进入一段与 Tap 不同的 opening phrase。
Hold > 350ms：进入持续节奏、Drone 或 Arpeggio。
Release：停止新事件，保留 2–3 秒尾音与视觉残影。

Audio 与 Visual 共同读取 BPM、Beat、Energy、Scene 和 Hold Duration。
随机只从有限 Pattern 中发生，并限制同时发声数量。
1 · 技术栈声音和视觉分别用什么做
2 · 输入只有一个按钮，还是鼠标、键盘、摄像头
3 · 时间与状态Tap / Press / Hold / Release 何时切换
4 · 音画映射哪些参数由双方共同读取
5 · 边界音阶、随机、并发数量和变化时机

如果只写“更酷一点、丰富一点”，AI 很容易加出一堆粒子、面板和随机动画，但不一定更好玩。

04 · 工具怎么选

工具不用全上，
看这一轮到底想验证什么。

Tone.js

想最快搭出 BPM、Transport、Sequencer 和合成器时很好用。适合第一轮验证节奏与状态。

Web Audio API

需要自己控制 Oscillator、Filter、Envelope、Delay、Reverb 或更细的声音调度时使用。

Canvas 2D

做二维粒子、线条、波纹和快速反馈最省事。很多想法用一个 HTML 就能先跑起来。

Three.js / WebGL

当重点是大量粒子、空间深度、3D 星图或 Shader，再换到这一层，不必一开始就增加复杂度。

最快的 MVP： Tone.js + Canvas 2D
视觉是重点： Web Audio API + Three.js / WebGL
项目继续长大： Vite + React / TypeScript
05 · 第二轮怎么改

不让 AI 重做一遍，
只改一个听得见的问题。

声音越来越乱

不要只说“好听一点”，直接限定音阶、并发数量和变化位置。

所有旋律限制在同一音阶；同时发声不超过 4 个；每 2 小节最多切换一次 Pattern。

长按二十秒很机械

准备少量可重复的变化，不要每一帧都随机。

准备 3–4 个 Pattern Variant；变化只发生在小节边界，并保留一个能被记住的 Motif。

视觉只是跟着声音抖

别只做频谱响应，让两边从同一套状态出发。

Audio 与 Visual 共同读取 Clock / State；视觉不是声音生成以后再附加的装饰。
先留住能跑的版本→ COMMIT→ 只改一个问题→ 实际试玩→ 保留或回退

06 · 我的案例：星宿合成器

原型很快出现，
音乐秩序要慢慢建立。

第一版很快就能点星星、看粒子、听声音。但继续玩下去，我发现它更像一组零散音效：有反应，却没有清楚的动机、Groove 和段落。

星图决定结构 STAR MAP

哪些星发声、先后顺序、何时一起闪、密度与空间位置。

文明决定声音语言 CULTURE

研究音阶、节奏、乐器与装饰方式，避免简单贴“民族音色”标签。

Techno 提供共同骨架 FORM

共享稳定 4/4、Kick / Bass、8 或 16 小节乐句，以及能量推进与释放。

这一步还在做。我想保留不同文明真正的音乐差异，同时让整件作品仍然有可以持续演奏的秩序。
