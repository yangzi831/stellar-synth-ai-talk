03 · Describe Relationships

少说“酷一点”，
多描述关系与边界。

“按下去要有感觉”
→
约 0.12 秒的短促声音，同时出现明确视觉冲击
“一直按住会变化”
→
Hold > 350ms，进入持续节奏与视觉状态
“不要太机械”
→
每 1–2 小节只从有限 Pattern Variant 中变化
“松开别马上没了”
→
Release 保留约 2 秒混响尾音与视觉残影
“音画要在一起”
→
Audio 与 Visual 共用 BPM、Beat、Energy 和 State
“别太乱”
→
限定音阶、随机范围、并发声音和最大密度
GESTURE → SHARED CLOCK / STATE → AUDIO + VISUAL
04 · What Breaks

能运行，
不等于能演奏。

01 · EFFECT

效果越堆越多

粒子、光晕、按钮和随机动画越来越丰富，但操作关系仍然只是“按一下，闪一下”。

02 · MUSIC

声音没有结构

单个音色似乎都成立，连续播放却缺少调性、律动、动机、段落与张力释放。

03 · VERSION

修改破坏旧版本

一次让 AI 改太多问题，很容易在优化视觉时破坏声音，或让原本稳定的交互消失。

能运行的版本→ COMMIT→ 只改一个问题→ 测试 / DIFF→ 保留或回退

同一片真实星空，在不同文明中成为不同的图像、故事与音乐结构。

05 · Stellar Synth

从生成效果，
走向音乐系统。

CURRENT · 星图 / 视觉 / 交互 IN PROGRESS · 音乐 / 编曲

AI可以很快生成“似乎像某种风格”的声音，但目前仍容易零散、无序，缺少统一调性、动机、Groove和能量曲线。

星图结构 STAR MAP

决定事件顺序、密度、力度、空间位置和星座之间的演奏关系。

文明声音语汇 CULTURAL VOICE

研究音阶、调式、节奏、乐器音色与装饰方式，避免只贴“民族风格”标签。

统一编曲框架 MELODIC TECHNO

用BPM、Kick/Bass、Groove、8/16小节乐句与Build–Release组织完整音乐。

星图是结构输入　·　文明音乐是声音语言　·　Melodic Techno 是编曲框架
